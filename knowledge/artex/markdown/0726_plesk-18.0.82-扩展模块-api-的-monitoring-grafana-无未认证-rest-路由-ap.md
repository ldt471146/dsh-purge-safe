## 描述

Plesk 扩展模块 API 面：已安装但未实现 REST API 的扩展（monitoring/grafana）不会返回 401/403，而是由网关回 Express 型 404「Cannot GET <完整URL>」；未知扩展 slug 则由 php-fpm 回 404/16B「File not found.」。该语义可作「扩展是否已注册挂载」的低价值 oracle。Cannot GET 页对 <、>、\" 做百分号编码，不构成反射型 XSS；Host 头明文进入正文 URL（无 Location/缓存头）。

## 用法

```
复现（直连，unset *_proxy）：
curl -sk --resolve mail.goffsgames.co.uk:8443:88.208.224.249 -A "$ARTEX_UA" "https://mail.goffsgames.co.uk:8443/api/modules/monitoring/v1/specification/public" -D - 
判据：404 + 正文 "Cannot GET https://…" = 该扩展已挂载但无此 REST 路由；404/16B "File not found." = 扩展未安装/未知 slug。若出现 401/48B Unauthorized = 扩展实现了端点但需认证（wp-toolkit 形态）。路由探测时注意区分 /api/modules/<slug>（无尾斜杠，404/0B 且带 ACAO:*）与 /api/modules/<slug>/（Cannot GET 处理层）。
```
