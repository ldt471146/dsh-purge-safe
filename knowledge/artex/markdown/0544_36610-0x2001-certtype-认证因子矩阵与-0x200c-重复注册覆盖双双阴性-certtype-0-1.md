## 描述

0x2001 登录的 certType 是客户端多值枚举、cert 语义随 certType 变化；本条目钉死其服务端行为与 0x200C 重复注册的拒绝语义，供后续不再重复测试。

## 用法

```
需要复用 36610 登录/注册时：按 content 的权威帧发；certType 只有 10+GetPWD(明文) 能登录；对已存在邮箱重复注册无法取得 Result=0，不要再试。
```

## 0x200C 重复注册（对已存在邮箱）
| 验证码形态 | Result |
|---|---|

| 000000 错码 | 3 |
