## 描述

做静态文件/备份/源码泄露枚举时，若宝塔 WAF 对 .bak/.old/.sql/.zip/.git/.env 等关键词返回 403|1200「网站防火墙」，注意：所谓「尾斜杠绕过」只让 WAF 放过、却改变了 nginx 实际请求路径，读不到任何真实文件。判据必须用「已知存在的文件」做对照。

## 用法

```
1) 先做对照校准：request 一个已知存在的静态文件（如 /bbs/robots.txt → 200/435B）。\n2) 再测绕过变体：/bbs/robots.txt/  、/bbs/robots.txt%3f  、/bbs/robots.txt%23  、/bbs/robots.txt%20  → 若这些【都变 404】，说明这些"绕过"只是改路径、nginx 找不到该文件，不能用于读真实文件；而 /bbs/robots.txt? 与 /bbs/robots.txt → 200，说明字面 '?' 保留路径但该变体不被 WAF 绕过。\n3) 结论口径：本站在【保留路径】前提下，对 .bak/.old/~/.swp/.sql/.zip/.git/.env/.user.ini 未找到可用绕过（%62/%61 伪装、大小写 .BAK 均被 WAF 解码/归一后 403）。遇到这类 403|1200 不要把它当"文件存在"或"唯一靠尾斜杠就能读"的证据。\n4) 另：原始 IP 直连 + Host 头思路在该站不可行（浏览器直连 IP 失败；平台/VPS 出口 80/443 被 TCP-DROP）。
```
