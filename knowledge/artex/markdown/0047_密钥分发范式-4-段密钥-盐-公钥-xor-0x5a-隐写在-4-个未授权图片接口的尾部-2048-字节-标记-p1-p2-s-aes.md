## 描述

**【该团伙的密钥分发范式 —— 遇到同团伙任何"前端解不开的加密信封"，第一步就翻图片接口尾部】**

前端 `webpack module 1483` 的 `KeyLoader` 把加密体系的密钥**拆成 4 段、以"图片尾部隐写"的方式藏在 4 个未授权资源接口里**：
· 载体：`GET /member/api/resources/logo`、`/banner`、`/icon`、`/topLogo` —— **无需任何凭据**（响应是标准 JSON `{"status":1,"msg":"SUCCESS","data":{"headers":{...},"body":"<base64 图片>"}}`，取 `data.body` 做 base64 解码）。
· 解码算法（逐字复刻 `parseHiddenData`）：取字节流**最后 `min(n,2048)` 字节**，**逐字节 `XOR 0x5A`（十进制 90）**，再按 UTF-8 解码（用 `errors=replace` 以免中断）。
· 标记与语义（`extract` = 取该标记**最后一次出现**之后的全部内容并 trim）：
  - `[P1]`（在 `/logo`）+ `[P2]`（在 `/banner`）→ **直接拼接**得 RSA **2048 位 SPKI 公钥**（base64，共 392 字符，以 `...IDAQAB` 结尾，e=65537）
  - `[S]`（在 `/icon`，64 字符）→ **请求签名盐**：`X-Signature = md5(X-Timestamp + salt).toLowerCase()`
  - `[AES]`（在 `/topLogo`，16 字符）→ **对称密钥**：`AES-ECB-PKCS7`，用于**请求体加密**与**服务端信封解密**（前端用 `AES.encrypt/decrypt(x, Utf8.parse(key), {mode:ECB, padding:Pkcs7})`）
· 前端组合逻辑：`init()` 并发 `load(0..3)` → `{p: p1+p2, s: s, aes: aes}` → 调用方 `keyStore.setKey(aes); keyStore.setSalt(s)`。

**自证方法（拿到任一同团伙目标时照做，全部零/极低请求）：**
1. 4 个 `GET /member/api/resources/{logo,banner,icon,topLogo}`（各 1 次）。
2. 尾部 2048 字节 XOR 0x5A，抓 4 个标记 —— **标记字符串自带定位，命中即是自证**。
3. `RSA.import_key(b64decode(P1+P2))` 必须解析成功且为 2048 位（证明拼接正确）。
4. 用它去解任意抓到的服务端密文信封（`{AA, data}` 的 `data`）：解出可读 JSON 即密钥正确

#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""Decode the STATICAES key material hidden in the tails of the resource responses.

Algorithm (webpack module 1483 parseHiddenData):
    n = len(bytes); a = min(n, 2048); r = n - a
    out[i] = 90 ^ bytes[r+i]          # XOR 0x5A over the LAST min(n,2048) bytes
    text = utf8(out)
    markers: [P1] [P2] [S] [AES]  -> value = text after LAST occurrence of the tag, trimmed
Reads runs/ky588_res_*.json (fetched with curl) when present.
"""
import base64
import glob
import json
import os
import sys

try:
    sys.stdout.reconfigure(encoding="utf-8", errors="replace")
except Exception:
    pass

TAGS = ["[P1]", "[P2]", "[S]", "[AES]"]
found = {}

for f in sorted(glob.glob(r"C:\rt\dgha\runs\ky588_res_*.json")):
    try:
        j = json.load(open(f, encoding="utf-8"))
    except Exception as e:
        print("%-34s not json (%s)" % (os.path.basename(f), e))
        continue
    b64 = (j.get("data") or {}).get("body")
    if not b64:
        print("%-34s no .data.body" % os.path.basename(f))
        continue
    raw = base64.b64decode(b64 + "=" * (-len(b64) % 4))
    n = len(raw)
    a = min(n, 2048)
    r = n - a
    out = bytes(90 ^ b for b in raw[r:r + a])
    txt = out.decode("utf-8", "replace")
    hits = [t for t in TAGS if t in txt]
    print("%-34s bytes=%-7d window=%-5d off=%-6d tags=%s" % (os.path.basename(f), n, a, r, hits or "-"))
    for t in hits:
        i = txt.rfind(t)
        v = txt[i + len(t):].strip()
        found[t] = v
        print("      %-6s -> %r (len %d)" % (t, v[:300], len(v)))
    if hits:
        open(f.replace(".json", "_tail.txt"), "w", encoding="utf-8").write(txt)

print("\n=== recovered ===")
for t in TAGS:
    v = found.get(t)
    print("%-6s len=%-4d %r" % (t, len(v) if v else 0, (v[:300] if v else "")))

if found:
    json.dump(found, open(r"C:\rt\dgha\runs\ky588_static_key.json", "w", encoding="utf-8"),
              ensure_ascii=False, indent=1)
    print("\nwritten runs/ky588_static_key.json")
    if found.get("[AES]"):
        print("AES KEY  =", found["[AES]"])
    if found.get("[S]"):
        print("SALT     =", found["[S]"])
    print("P1+P2    =", (found.get("[P1]", "") + found.get("[P2]", ""))[:200])
