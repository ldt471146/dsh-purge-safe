## 描述

中文站群常见的自研/面板自带"网站防火墙"WAF：命中时返回 HTTP 403 + 固定长度 1200 字节的中文拦截页（<title>网站防火墙</title>，带"宋体"样式，md5 前缀 032e6875）。拦截维度是【文件名/扩展名】而非路径：zip/rar/sql/bak/old/~ /swp/shell.php 等一律 403。关键判据：在同一目标上同时存在多种 404/403 长度，可用来区分类别 —— 403+1200B = WAF 拦截；426B = phpwind 软 404；138B/371B = nginx 自身 404（371B 那版可能带第三方注入 JS）。用途：避免把"被 WAF 拦的备份文件"误判为"文件不存在"，并据此选绕过变体。

## 用法

```
1) 先发一个肯定不存在的路径拿"基线 404"长度；2) 再请求备份/源码包（/www.zip、/db.sql、/data/sql_config.php.bak）——若返回 403 且长度固定（如 1200），即 WAF 而非"不存在"；3) 用长度分类：1200=WAF拦截、426=phpwind软404、138/371=nginx 404；4) 绕过优先试这 10 个高价值变体（单目标 ≤3 req/s，10 req/s 会触发 nginx limit_req 使结果失真）：`/data/sql_config.php.BAK`、`%2ebak`、`%252ebak`、`;.bak`、`.bak?x=1`、`//www.zip`、`./www.zip`、`/www%2Ezip`、`.php.txt`、`.php.bak/`。
```
