## 描述

166 站（docroot=/www/wwwroot/kkjjer_com）后台鉴权集中在 CommonAction::_initialize（非白名单 Host 一律 302→/Admin/Index/login），但 Admin 组里 Autoart 与 Wechat 两个控制器写成 extends Action，整段跳过鉴权。实测零 Cookie 即可 GET /index.php?g=Admin&m=Autoart&a=kjer（200/88964B 开奖记录列表）、a=indexam（200/64084B 帖子管理，含文章 ID/作者/单价/销量）、a=catlist（200/42306B）；POST a=editkjer 可新增/修改开奖记录（回显「编辑成功!」），把 id=6101 特码 07→44 后在列表读回 44、再改回 07，构成完整未授权写→读闭环；POST a=article_save 返回生成条数（ids=8_54 → 1）亦为未授权写库。作为对照，同一 Admin 组的 8 个继承 CommonAction 的控制器（Admin/User/Article/System/Block/Payorder/Daikuan/Api）无论 GET/POST 均 302 到登录页，说明是 Autoart/Wechat 自身脱队而非全局无鉴权。
