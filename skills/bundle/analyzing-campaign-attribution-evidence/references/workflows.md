# 攻击活动（Campaign）溯源归因（Attribution）分析工作流程

## 工作流程 1：情报收集与分析
```
[情报来源] --> [数据收集] --> [分析] --> [报告]
      |                |               |              |
      v                v               v              v
  OSINT/HUMINT/SIGINT  规范化/富化   评估/关联    传播分发
```

### 步骤：
1. **规划（Planning）**：定义情报需求和收集优先级
2. **收集（Collection）**：从相关来源汇聚数据
3. **处理（Processing）**：规范化数据格式并过滤噪声
4. **分析（Analysis）**：应用分析框架并关联发现结果
5. **生产（Production）**：生成情报产品和报告
6. **传播（Dissemination）**：通过适当渠道与利益相关方共享
7. **反馈（Feedback）**：收集消费方反馈以优化未来收集工作

## 工作流程 2：持续监控
```
[监控列表] --> [自动化监控] --> [变化检测] --> [告警/更新]
```

### 步骤：
1. **定义监控列表（Watchlist）**：识别需要监控的指标、威胁行为者和主题
2. **配置监控**：从相关来源建立自动化收集
3. **变化检测（Change Detection）**：识别新增或变更的情报
4. **评估**：评价变化的重要程度
5. **告警**：向利益相关方通知重要情报更新
6. **归档**：存储情报以供历史分析和趋势研判
