# 社工库资源目录与甄别

上游素材：`C:\Users\Administrator\.dsh\skills-src\xgit01__sgkrank\sgkrank-master\README.md`（426 行，2026-10 版，纯目录，无代码）。

## 一、这份素材的形态（先认清）

- 就是一张**排行榜**：每条 = 名称 + 星级 + 一句卖点 + 一个入口链接 + 截图。
- 没有技术实现、没有数据样本、没有验证方法 → **它的判断全是广告文案**，不能当证据。
- 通篇卖点集中在"最全/最新/独家/免费次数"，这类词本身就是风险信号。

所以正确用法：把它当**目录骨架**，而不是当推荐清单。

## 二、目录结构（按需求分类，不用它的排序）

```
SRC_A 身份户籍类   ← 身份证/姓名/户籍/案件
SRC_B 快递外卖类   ← 收件人/地址/订单号（旧库多来自 2019-2021）
SRC_C 车辆车主类   ← 车牌/车架号/车主
SRC_D 社交账号类   ← QQ/微博/微信原始ID/贴吧/小红书
SRC_E 企业工商类   ← 法人/股东/统一信用码（公开源可替代）
SRC_F 教育学历类   ← 学籍/院校/毕业年份
SRC_G 金融贷款类   ← 借贷/征信相关（最敏感，量刑最低门槛）
```

每条填这几个字段（模板）：

```yaml
id: SRC_A
type: 身份户籍
entry: PLACEHOLDER_BOT_OR_SITE
data_years: "2021 前 / 2021-2023 / 2024+"
fields: [name, id_no, phone, addr]
free_quota: "n 次/日"
evidence: "无 / 截图 / 可复现样例（脱敏）"
verdict: 可用 / 存疑 / 蜜罐
```

## 三、五维评分（替代它的"五星"）

| 维度 | 怎么判 | 权重 |
|---|---|---|
| 数据年份 | 越新越有用；2021 前的手机号/住址错配率高 | 30% |
| 字段覆盖 | 能否按 **手机号/邮箱/身份证号** 任意一个反查 | 25% |
| 验证方式 | 给**脱敏样例**且能对上你手上的公开信息 → 可信 | 20% |
| 可复现证据 | 同一查询两次结果一致；换字段能互相对上 | 15% |
| 获取成本 | 要转发/拉人/装客户端/充值 → 扣分 | 10% |

评分 ≥4/5 才值得继续；<2 直接划掉。

## 四、蜜罐与钓鱼特征（命中两条就别碰）

- 要求**先转发到 N 个群**或拉 N 个人才给查；
- 要求**装它的"查询客户端"**（安卓 apk / Windows exe）；
- 只给**群内截图**、不给样例；问"能不能查我自己的手机号验证一下"就装死；
- 充值页做成**第三方支付/虚拟币**，无退款说明；
- 域名/IP 与宣传品牌不一致，whois 隐私保护且注册 <6 个月；
- 查询"任何号码都返回结果"，包括明显无效的 13800000000。

这些里有一种常见意图：**收你的手机号/微信/TG 号 + 设备指纹**，再反向卖。

## 六、可替代的公开源（多数需求在这就解决了）

| 想查 | 公开替代 |
|---|---|
| 企业/法人/股东 | 国家企业信用信息公示系统、天眼查公开页 |
| 域名/子域/证书 | crt.sh、FOFA、SecurityTrails |
| 邮箱是否泄露（自查） | HIBP 域名查询 |
| 代码/密钥泄露 | GitHub 搜索 + gitleaks/trufflehog |
| 手机归属地 | 公开号码标记库（只到城市级） |
| 人员职务/单位 | 领英/脉脉公开页、招投标公告、公众号 |

覆盖了报告里 80% 的"人员维度"需求，且每条能写出处。

## 七、登记台账（必须做）

```jsonl
{"at":"2026-10-24T04:00:00","src":"SRC_A","type":"身份户籍","score":3.2,
 "checked":"样例1条可对上公开信息","note":"收费 0.5U/次","verdict":"存疑"}
```
- 每条记录只写**判断与依据**，不抄库内容；
- 命中量单独记（`osint-people` 的 ledger 口径）；
- 报告里引用时写"来源类型 + 验证方式"，不写具体机器人名。

## 八、结论口径

- 这类目录的价值在**分类与筛法**，不在具体链接（链接半年就死一半）。
- 真正能进报告的永远是：**公开源事实 + 可复现证据**。
- 库检索只在本地离线、数据在你自己手上的时候做（见 `sgk-local-stack`），不要为了"查一下"去第三方那里留痕。
