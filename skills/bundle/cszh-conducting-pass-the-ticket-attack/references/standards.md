# 标准与框架参考

## MITRE ATT&CK

| 技术 ID | 名称 | 战术 |
|-------------|------|--------|
| T1550.003 | 使用替代认证材料：票据传递（Pass the Ticket） | 横向移动 |
| T1003.001 | OS 凭据转储：LSASS 内存 | 凭据访问 |
| T1558 | 窃取或伪造 Kerberos 票据 | 凭据访问 |
| T1021.002 | 远程服务：SMB/Windows 管理共享 | 横向移动 |

## Kerberos 票据类型

| 票据 | 用途 | 有效期 | 加密方式 |
|--------|---------|----------|-----------|
| TGT（票据授予票据，Ticket Granting Ticket） | 向 KDC 认证以请求 TGS | 默认 10 小时 | krbtgt NTLM 哈希 |
| TGS（票据授予服务票据，Ticket Granting Service） | 向特定服务认证 | 默认 10 小时 | 服务账户哈希 |

## 检测 - Windows Event ID

| Event ID | 描述 | 票据传递指标 |
|----------|-------------|---------------|
| 4768 | TGT 请求 | 已知用户的异常源 IP |
| 4769 | TGS 请求 | 来自意外主机的服务访问 |
| 4770 | TGT 续期 | 与原始 IP 不同的续期来源 |
| 4771 | Kerberos 预认证失败 | 可能表示票据重用尝试 |
